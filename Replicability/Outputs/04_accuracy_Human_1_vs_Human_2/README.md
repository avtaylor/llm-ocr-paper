# Reference-based agreement

Human 1 is a comparison reference, not adjudicated truth. Accuracy = exact normalized matches / populated reference cells; candidate missing values count as errors. Values against reference blanks are reported separately. Both-missing values are excluded. Aggregate rates pool cells, not facility percentages. All eligible shared fields form the main summary; a separate summary restricts to the 15 requested indicators. Card fields count once using first populated values and inconsistent repetitions are flagged. Visit fields count per matched visit. Unmatched cards and visits are coverage gaps, excluded from the cell denominator.

Facility/district membership and manual exclusions come from the saved card matches. All-missing reference fields are detected over the full reference before filtering. Agreement to follow-up and the fourth HIV test are excluded. NA and empty values are equivalent. Categorical codes ignore capitalization, spaces and punctuation (On ART equals OnART; N.A.D. equals NAD), matching the earlier OCR convention. Other text ignores case/extra whitespace; numeric values compare as decimals; HCC facility prefixes are removed; dates use ISO/day-first formats. Bare 1 and 6 in enrolment age/NVP duration mean 1 day and 6 weeks respectively. No clinical synonym recoding or multi-label interpretation is applied.

Kappa is computed separately for the seven categorical indicators using both-populated pairs; the alternative treats one-sided missingness as a category. No pooled/numeric/date kappa. Date errors use valid calendar pairs and days; thresholds 1,7,14 days. Numeric tolerances: 0.1 kg weight/birth weight, 1 cm height, 1 month age. CPT is numeric recorded dosage units, with no inferred unit conversion. Tolerance rates are supplied for valid pairs and populated reference denominators. Invalid recorded numeric/date strings remain in exact agreement, but are excluded from error magnitudes and flagged by counts. Extreme values are retained; largest errors are listed.

Visit matching uses unique age+date, date, then age, with no positional fallback. Age/date agreement is influenced by selection; independent age-only pairing for visit date and date-only pairing for age are reported separately. Some card matches use birth date, making birth agreement conditional on that selection. Clinical monitoring means abdominal_exam; mother status is visit-level mother_status. No confidence intervals are estimated for clustered visits.
