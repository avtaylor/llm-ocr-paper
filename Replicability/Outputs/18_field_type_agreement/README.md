# Agreement by field type

Human 2 is compared with Human 1 on their shared cards across the 14 facilities. Each OCR is scored on the subset of those cards matched to the same OCR card in both references. GPT app is excluded. All reports use fields eligible in the H2-versus-H1 comparison, so fields blank throughout H1, including HIV sample IDs, are excluded from the OCR–H2 summaries too.

Pairwise exact agreement divides matches by populated reference values. Errors include omissions and different populated values. Unsupported additions are reported separately. The per-field CSV retains existing date and numeric tolerance statistics and kappa for the seven designated categorical indicators. CPT is its own group. The legacy NVP start field is separated from the other date fields.

Three-way agreement uses aligned cells populated by both humans. OCR accuracy on human consensus uses the subset where the human values also agree. Blank OCR values count as disagreements. The combined table shows both directions of human agreement, each divided by the number of populated values in its reference, alongside OCR accuracy on human consensus. The recording-method tables use the form inventory. The preprinted group contains only visit age. Unique child ID has a mixed recording method and appears only in the per-field table. The legacy NVP start field is grouped with handwriting because the inspected form asks for initiation age. Group rates pool cell counts. Age and visit date help align visits, so agreement on these fields is conditional on matching. Identifiers may contribute to card matching.
